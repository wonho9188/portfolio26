# 홈 로봇 월드 · 2026-11-20

이 문서는 현재 소스의 홈 월드 구현을 설명합니다. 공개 배포 상태는 해당 커밋의 GitHub Actions 실행 결과와 공개 사이트를 기준으로 확인합니다.

## 페이지 구조

- `/`: 배너 문구와 주행 로봇 월드. 소개·작업·경력 본문은 중복하지 않습니다.
- `/about`: 이전 홈의 7개 섹션을 옮긴 About Me. 프로필·업무 방식·작업·기술 기록·경력·수상·취미 내용을 유지합니다.
- `/work/:projectId`, `/side-work/:projectId`: 프로젝트 상세. 기존 `content.ts`의 참여 내용과 제공 자료, 관련 기술 글을 사용합니다. 미제공 성과·수치·프로젝트 사진을 새로 꾸며내지 않습니다.

## 월드와 상호작용

`src/data/world.ts`의 여덟 지점이 방문 위치·제목·요약·이동 주소의 기준입니다. 다섯 프로젝트와 About Me·Tech Blog·Life & Thoughts를 배치했습니다.

- 로봇은 네 바퀴·범퍼·라이다를 갖춘 가상의 AMR입니다. 실제 로봇의 제어나 물리·충돌 검증을 수행하지 않는 포트폴리오 탐색용 장면입니다.
- 도로는 닫힌 곡선이고, 선택한 목적지까지 짧은 방향으로 이동합니다. 이동 중에는 설명을 감추고 도착하면 해당 카드만 표시합니다.
- 도착한 뒤 약 6.5초 후 다음 장소로 이동합니다. 카드에 마우스가 올라가거나 키보드 초점이 있으면 자동 이동을 멈춰 읽을 시간을 보장합니다.
- 지도 마커 또는 하단의 장소 버튼으로 목적지를 고릅니다. 설명 카드 전체가 링크이며 실제 프로젝트 상세 또는 해당 메뉴로 이동합니다.
- 일시 정지 상태·모션 줄이기 설정·캔버스가 화면 밖에 있을 때 장소를 선택하면 목적지의 정지 화면으로 즉시 전환합니다. 조작할 수 없는 화면 밖의 애니메이션을 기다리게 하지 않습니다.
- WebGL을 사용할 수 없거나 컨텍스트가 끊기면 SVG 지도와 동일한 장소 버튼·카드·링크를 제공합니다.

## 구현과 성능

- `WorldHero.tsx`: 목적지·도착·읽는 중·자동 이동 상태, HTML 마커·카드·키보드 조작.
- `RoverWorld.tsx`: 지연 로딩한 Three.js 렌더러, 시점·크기·테마 동기화와 리소스 정리.
- `RoverScene.ts`: 둥근 월드 바닥, 도로·랜드마크·AMR의 실제 3D 메시.
- `world-motion.ts`: 폐곡선의 이동·도착 판정. 화면 크기와 무관하게 같은 방문 지점에 도착합니다.
- 장면은 매 프레임 React 상태를 갱신하지 않습니다. 도착 후 대기, 화면 밖, 숨겨진 탭에서는 연속 렌더링을 멈춥니다. 이동·크기·테마 변경 때만 필요한 프레임을 요청하며, 해제 시 기하·재질·렌더러를 정리합니다.
- 라이트·다크 모드는 사이트 토큰을 따릅니다. 기존 로봇팔 소스·이미지는 보존하지만 새 홈의 런타임에서는 사용하지 않습니다.

## 반응형·접근성

- 데스크톱의 설명 카드는 장면 오른쪽에 떠 있고, 작은 화면에서는 지도 아래의 예약된 카드 공간을 사용합니다.
- 3D 장면의 보조 정보와 조작은 HTML입니다. 장소 버튼과 링크는 키보드로 사용할 수 있고, 모션 줄이기 상태에서도 프로젝트에 접근할 수 있습니다.
- About Me 메뉴는 데스크톱·접힌 메뉴 모두 같은 경로입니다. 기존 햄버거/X 전환과 스크롤 헤더를 유지합니다.

검사: 빌드, 목적지 이동·자동 순회·카드 링크·직접 URL 및 새로고침·About Me 콘텐츠 보존·정지·모션 줄이기·WebGL 대체 지도·반응형 레이아웃. 렌더링 검사는 실제 WebGL과 대체 지도를 구분합니다.
