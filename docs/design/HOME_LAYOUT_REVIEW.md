# 홈 레이아웃 검토 · 2026-11-16

## 판단과 수정

글자 크기에 비해 내용 묶음 사이의 공간이 좁고, 설명과 제목의 명도가 비슷해 모든 정보가 동시에 강조되고 있었습니다. 글자를 일괄 축소하지 않고 읽기 폭, 간격의 단계, 강조의 순서를 조정했습니다.

## 전체 흐름

배너의 시각적 인상 → 개발자 소개 → 이해·설계·실현의 기준 → 실제 작업 → 작업을 돕는 역량 → 기술적 기록 → 경력의 근거 → 취향과 생각 → 연락의 순서를 유지합니다.

작업은 이미지 중심, 사이드 작업과 경력은 행 중심, 기술 글은 넓은 읽기 열 중심으로 구분합니다. 같은 모양의 큰 카드가 끝까지 반복되지 않도록 했습니다. 제목·핵심 문장은 `ink`, 설명은 `muted`, 분류·링크는 `accent`를 사용합니다. 18px 본문과 기존 색상 체계는 유지했습니다.

홈은 전체 기록의 입구이므로 기술 글은 4개로 제한합니다. 내용을 삭제하거나 접어 숨기지는 않았고, 전체 목록과 상세 글을 유지합니다. 경력은 사용자가 구분해 달라고 요청한 실무 경력·기타 경험을 모두 표시합니다. 이 때문에 경력 구간은 여전히 길지만, 내부 간격은 섹션 전환보다 작게 두어 하나의 근거 자료로 읽히게 합니다.

## 구현과 검증 범위

- `src/styles/home.css`는 `.home-page` 안에서만 적용합니다. 서브 페이지의 글 목록·상세 레이아웃과 스크롤 헤더는 기존 동작을 유지합니다.
- 홈의 소개 문구와 레이아웃은 `src/pages/Home.tsx`, 공통 글꼴·색상은 기존 스타일을 사용합니다.
- 분리된 Chromium에서 320·375·768·1024·1440px의 전체 화면과 라이트·다크의 대표 화면을 확인합니다. 시각 검토용 캡처는 추적하지 않는 `artifacts/home-flow-*`에 저장합니다.
- 가로 넘침·제목 잘림·실행 오류를 검사하고, 기존 메뉴·글 연결·테마·스크롤 헤더 검사를 실행합니다. 실제 사용자 대상 사용성 연구 결과를 의미하지 않습니다.
