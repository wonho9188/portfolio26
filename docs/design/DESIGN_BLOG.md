2026년 11월 20일 확인한 Figma, Webflow, Squarespace 공식 글을 바탕으로 타이포그래피·정돈된 인덱스·반투명 레이어·의미 있는 모션을 선정했습니다. 시장 전체의 순위를 주장하지 않으며 적용 메모는 작성자의 해석으로 구분합니다. 예시 화면은 이 프로젝트에서 직접 구성한 HTML/CSS이며 원문 이미지를 복제하지 않습니다.

출처는 각 예시와 함께 표시합니다. 예시 선택은 네이티브 버튼으로 조작하며 모션은 사용자가 누를 때만 실행합니다. 움직임 줄이기 설정에서는 전환을 제거하고 상태 문구를 유지합니다. 라이트·다크 토큰을 사용하고, 모바일의 탭 스크롤과 본문 폭을 확인합니다.

배포 상태는 GitHub Actions의 해당 커밋 실행 결과와 공개 사이트를 기준으로 확인합니다.

## 기술 블로그 목록 배치

기술 블로그의 주제별 목록은 `tech-post-grid`로 구분합니다. 1600px 이상은 4열, 1200–1599px은 3열, 768–1199px은 2열, 767px 이하는 1열입니다. 간격은 24px(모바일20px), 카드 안쪽은24px(모바일20px), 제목22px·요약16px·메타14px로 구성합니다. 카드 높이는 내용에 따라 늘어나며 제목·요약을 줄 수로 자르지 않습니다. 글 순서와 링크는 유지하고, Life 목록과 가이드의 단독 목록 예시는 기존 배치를 사용합니다.

## 톤 앤 매너와 룩앤필

표현의 방향과 경험의 결과라는 교육용 구분으로 설명하며 실무에서 용어가 겹칠 수 있음을 밝힙니다. 톤 앤 매너를 문구에만 한정하지 않고, 비교 예시에서만 말투와 시각 표현을 분리합니다. 말투 3종과 화면 3종을 조합할 수 있으며 CTA의 이동 목적지는 `/work`로 유지합니다. 미리보기의 색상은 자체 따뜻한 팔레트이며 전체 사이트 테마나 사용자 설정을 바꾸지 않습니다. NN/g의 톤 오브 보이스와 Figma 브랜드 스타일 가이드를 참고한 자체 예시입니다.

## 컴포넌트의 종류

행동·입력과 선택·탐색·정보 표시·피드백은 이 글의 교육용 분류입니다. USWDS 공식 컴포넌트 설명을 참고하되 USWDS 코드나 스타일을 가져오지는 않습니다. 예시는 버튼·입력·셀렉트·체크박스·탭·진행 표시를 네이티브 요소로 조작하며, 탭은 방향키/Home/End 및 연결된 패널을 지원합니다. 카드 예시는 기존 `PostCard`를 재사용합니다. 입력값과 진행 상태는 현재 예시 안에서만 바뀌며 저장·전송하지 않습니다.

## 시각적 우선순위

레이아웃·여백·크기·색상을 독립적으로 켜고 끄거나 모두 적용하는 예시를 제공합니다. 모든 상태에서 문구와 DOM 읽기 순서를 유지하며, 모바일은 한 열로 쌓습니다. 색상 모드에서도 텍스트 대비를 유지하고 색 이외의 위치·크기·문구로 중요도를 전달합니다. NN/g와 Figma 원리를 참고한 자체 화면이며 실측 시선·사용성 결과를 주장하지 않습니다. 예시의 프로젝트 링크는 실제 작업 상세로 이동합니다.

## 레퍼런스 관찰 연습

같은 문구를 유지한 비교 A/B를 크기·위계, 여백, 정렬 기준으로 나누어 봅니다. NN/g와 Figma의 시각 디자인 원칙을 관찰 기준으로 참고하며, 연습 순서와 화면 예시는 이 글의 제안입니다. 특정 연습 시간이나 향상 효과를 검증된 수치처럼 주장하지 않습니다. 원문 이미지를 복사하지 않고 자체 HTML/CSS 예시를 사용하며 비교는 선호도·사용성 실험 결과가 아닙니다. 기존 디자인 글 2개와 목록·이전/다음으로 연결합니다.

## 스타일 가이드와 컴포넌트

공통 규칙과 재사용 화면 요소의 차이를 설명한 뒤 실제 사이트 값을 보여줍니다. 색상은 실행 중인 CSS 변수를 읽고 테마 변경을 감지합니다. 폰트 샘플 6종, 간격 토큰 일부, 반응형 최소 여백과 읽기 폭, 반경을 소개합니다. 표기된 폰트 크기는 해당 샘플 값이며 사이트 전체의 고정 크기를 뜻하지 않습니다. 간격 막대는 토큰 크기의 상대 비교입니다.

`PostCard`, `PostRow`, `TextLink` 및 칩의 공통 CSS를 재사용합니다. 버튼은 이 글에서 상태를 비교하는 표현 예시이며 동작·초기화·선택·비활성 상태를 제공합니다. 컬러 값과 현재 여백은 테마·화면 폭에 맞춰 갱신됩니다. 12/8/4열은 설계 안내이며 실제 사이트를 고정 열에 강제하지 않습니다. 가이드 내 테마 버튼은 실제 사이트 모드 선택을 변경하고 저장합니다.

## 작은 슬라이드로 읽기

디자인 글도 소개 → 항목별 예시 → 정리 순으로 읽습니다. 디자인 트렌드와 스타일 가이드, 레퍼런스 관찰은 각 6장, 시각적 우선순위는 4장, 컴포넌트의 종류는 7장, 톤 앤 매너와 룩앤필은 5장입니다. 다음 버튼은 트렌드·가이드·관찰 기준·컴포넌트 역할의 다음 항목을 선택한 상태로 엽니다. 예시 안의 비교 탭은 그대로 사용할 수 있습니다. 조작과 결과는 같은 슬라이드에 둡니다.

슬라이드 구성은 src/data/lesson-slides.ts, 선택 렌더링은 LessonParts에서 관리합니다. 제목과 글 주소는 유지하고 ?screen=N만 바뀝니다. 본문을 잘라 숨기지 않으며 기존 문단·표·출처를 보존합니다.
