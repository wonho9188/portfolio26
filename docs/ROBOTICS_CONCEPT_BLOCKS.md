# 차곡차곡, 로보틱스 개념 블록

작은 개념을 하나씩 이해하고, 블록처럼 연결해 로봇이라는 큰 구조를 알아가는 기술 블로그 연재입니다. 독자의 나이를 제한하지 않고, 한 번에 이해할 수 있는 정보 단위를 기준으로 글을 나눕니다.

## 글을 추가하는 방법

1. `docs/examples/robotics-post.json`의 작성 틀을 복사합니다. 작성 틀 자체는 공개 목록에 포함되지 않습니다.
2. 고유한 `slug`, 제목, 요약과 본문을 작성합니다.
3. `src/data/posts-source.json`의 `posts` 배열에 추가합니다.
4. 저장소에 반영하면 GitHub Actions가 검사·빌드·배포합니다.

별도의 웹 관리자 편집 화면은 없습니다. 대화에서 글 작성을 요청하거나 저장소의 글 파일을 수정하는 현재 방식을 사용합니다.

## 필드

| 필드          | 설정                                                               |
| ------------- | ------------------------------------------------------------------ |
| `kind`        | `tech`                                                             |
| `group`       | `robotics-concept-blocks`                                          |
| `slug`        | 다른 글과 겹치지 않는 영문·숫자·하이픈 주소                        |
| `seriesOrder` | 읽는 순서. 1, 2, 3처럼 입력합니다.                                 |
| `title`       | 이 글에서 이해할 개념을 드러내는 제목                              |
| `excerpt`     | 다룰 개념과 질문을 짧게 소개                                       |
| `category`    | `ROBOTICS` 등 글에 맞는 분류                                       |
| `meta`        | 연재 회차 등 실제 정보만 입력                                      |
| `status`      | `draft`: 초안 표시, `planned`: 작성 예정 표시, `record`: 완성한 글 |
| `sections`    | 소제목, 문단 배열 `p`, 필요하면 `bullets`                          |

초안과 작성 예정 글도 기존 사이트 방식대로 목록에 표시됩니다. 완성한 글은 `record`로 변경하면 초안 안내 없이 읽을 수 있습니다. 실제 본문이 없는 완성 글은 등록하지 않습니다.

## 구성 원칙

- 한 글에는 중심 개념 하나를 담습니다.
- 개념을 이해하는 데 필요한 설명을 작은 문단으로 나눕니다.
- 일상적인 비유를 썼다면 실제 로봇 원리와 어떻게 대응하는지 연결합니다.
- 끝에서는 이해한 개념이 다른 개념과 어떻게 이어지는지 정리합니다.
- 설명의 크기를 줄이되, 필요한 조건과 정확한 용어를 생략하지 않습니다.

등록된 글은 이 주제 목록에서 `seriesOrder` 순서로 나타납니다. 상세 글의 목록 복귀와 이전·다음 이동도 같은 연재를 유지합니다.
